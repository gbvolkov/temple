# Просмотр сайта с черновиками

Режим и исправление production-маршрута развёрнуты 24 ноября 2026 года для вошедших пользователей CMS: viewer, editor, publisher, admin.
Анонимная, истёкшая или отключённая учётная запись доступа не получает.

## Как открыть

1. Обновите открытую CMS (Ctrl+F5) и войдите в неё в этом браузере. Чтобы увидеть последние правки, сначала
   нажмите **«Сохранить»**: режим использует сохранённые рабочие версии.
2. Нажмите **«Сайт с черновиками»** в верхней панели на компьютере или в начале
   бокового меню **☰** на телефоне: обычный сайт с рабочими
   версиями откроется в текущей вкладке. При несохранённых правках можно сохранить
   их перед переходом, перейти без сохранения или остаться в редакторе. Либо откройте
   `https://cms.temple.gbvolkoff.name:8443/preview?preview=drafts`.
3. Переходите по разделам, карточкам, годам, страницам списка и результатам поиска:
   параметр сохраняется. Вверху показывается полоса **«Предпросмотр черновиков»**.
4. Нажмите **«Выйти из предпросмотра»**, чтобы открыть обычную главную страницу.

| Область | Поведение |
|---|---|
| Материалы | Показываются текущие рабочие версии всех активных материалов, включая миграционную очередь и ещё не опубликованные правки опубликованных материалов. |
| Архив и корзина | Исключены из списков, карточек, связей и поиска. |
| Статусы, миграционные флаги, публикации | Просмотр их не меняет. |
| Поиск | Отдельный временный индекс в памяти запроса; публичный индекс не изменяется. |
| Внешний посетитель | Обычные URL показывают только опубликованные редакции, даже если пользователь CMS открыл preview в другой вкладке. |
| Авторизация | Проверяется на каждом запросе с параметром. Ссылка без действующей сессии не открывает черновики. |
| Формы записок и школьных заявок | Отключены в интерфейсе; запросы записи с параметром preview отклоняются сервером. |
| RSS, sitemap, social preview и файлы | Остаются в обычном публичном режиме; режим не создаёт публичных превью черновиков. |
| Индексация и кэш | HTML `noindex,nofollow`, HTTP `X-Robots-Tag: noindex, nofollow`, `Cache-Control: private, no-store`, `Vary: Cookie`. |

По последнему протоколу доступны 1 224 активных документа: 800 принятых
черновиков и 424 миграционных. Состав изменяется по мере работы редакции;
533 архивные новости в этот режим не включаются.

Это просмотр рабочих версий, а не проверка их готовности к публикации:
в миграционных материалах могут отображаться ещё не решённые содержательные вопросы.

## Проверка реализации

Постоянные тесты проверяют все роли, отсутствие/истечение/отключение сессии,
актуальную рабочую редакцию, изоляцию параллельных обычных и preview-запросов,
архив/корзину, поиск без изменения публичного FTS, пагинацию/годы/связи,
редиректы, заголовки, недоступность записи и неизменность логического содержимого БД.
Playwright проверяет вход из CMS, переходы, поиск, мобильный вид, отключённые формы
и выход. Source-data профиль проверяет публичные разделы и карточки реального
исходника на отдельной копии с подтверждением неизменности БД при просмотре.

Приёмка: server 257/257, smoke 3/3, full 56/56, source-data 11 проверок
с ожидаемым GAP-01 и неизменным исходником. Данные production также не изменены.
Артефакты: `output/draft-preview/release/`. Подробности —
[протокол приёмки](cms-site-draft-preview-verification.md).

Исправление входа через CMS-домен и проверка реального браузера: [протокол](cms-site-draft-preview-routing-fix.md).
